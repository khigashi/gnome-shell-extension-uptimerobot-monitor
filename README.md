## 💡 Description

Displays tray and desktop notifications when UptimeRobot reports downtime for a monitored website or service.

## 🦄 Installation

Available on the [GNOME Extensions Store](https://extensions.gnome.org/extension/8321/uptimerobot-monitor/)
